## Projects

### [YouTube Backend API](https://github.com/absar22/youtube-backend)

A backend project for a video platform built to understand how production-style backend applications are structured.

Features include:

- User registration and login
- JWT access and refresh tokens
- HTTP-only cookie authentication
- Password hashing with bcrypt
- Protected routes and authorization
- File uploads using Multer
- Media storage with Cloudinary
- MongoDB aggregation pipelines
- MVC project structure

**Stack:** Node.js, Express.js, MongoDB, Mongoose, JWT, bcrypt, Cloudinary, Multer
